Problem statement

Efficient navigation of autonomous robots in warehouses requires suitable paths through constrained spaces while avoiding obstacles. This project models the warehouse as a Markov Decision Process and computes a navigation policy using Asynchronous Dynamic Programming.

Objectives

  • Model the warehouse as an MDP.
  • Define states, actions, transitions, and rewards.
  • Compute a policy with in-place asynchronous updates.
  • Generate a path from Start to Goal.
  • Simulate obstacle-aware robot movement.
  • Compare asynchronous and synchronous DP.

In-place async update

Initialize V(s) = 0
Select next state in row-major order
Calculate max action value
Immediately write V(s)
